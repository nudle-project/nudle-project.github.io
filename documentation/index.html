NudleOS Install Guide

This guide will walk you through the steps to install NudleOS on your system. Make sure to follow each step carefully to ensure a successful installation.

Step 1: Download NudleOS

First, download the latest version of NudleOS from the official repository. Make sure to verify the integrity of the downloaded file.

Step 2: Prepare Your System

Ensure that your system meets the minimum requirements for NudleOS. Back up any important data before proceeding with the installation.

Step 3: Install NudleOS

Use the NudleOS ISO image, preferably 1.0.3, and install it onto the USB drive. Plug it into your device and wait for everything to boot up. Partition your disk drive into the Expansion Drive, Swapspace, and Boot Drive using the prompt --partition command. Next, install all essential packages with npk --install:packages.Boot.Filesystem.npkg?NudlePackage.xshell. After this command, change drives using chdrv --swap?Expansion.sda. Finally, restart and install a desktop package.

Step 4: Post-Installation Setup

After installation, complete the initial setup, including creating user accounts and configuring system settings.
